
# LTXX-Sector-File
LTXX FIR plugins and configurations for the Turkish Euroscope sector file used on VATSIM.

This repository contains non-automatically generated files from our sector file provider AeroNav GNG, including:
- Plugins
- Settings
- Manuals

## Contributing
Anyone can contribute to this project. However, all proposed changes must first be submitted to the **NAV Change Board** on our Discord server for discussion and approval.

Change requests must follow the submission format provided in [CHANGE_REQUEST_TEMPLATE.md](CHANGE_REQUEST_TEMPLATE.md).

**Explicit approval must be obtained through the NAV Change Board before proceeding with implementation or submitting a Pull Request.**

Once approved, contributors may submit a Pull Request referencing the corresponding Discord discussion. A member of the sector-file team will review the implementation before it is merged.

**Pull Requests submitted without prior approval will not be accepted.**

For additional contribution guidelines, see [CONTRIBUTING.md](CONTRIBUTING.md)

## Bugs, feedback & suggestions
We use GitHub's issue board to track sector file-related matters, including:
- Bug reports
- Feature suggestions
- Discussions
- Documentation

> [!TIP]
> If you have observed any bugs or have suggestions for the sector file, please create an issue on GitHub.
>
> Creating an issue does not constitute change approval. Any proposed implementation must first be discussed and approved through the NAV Change Board on Discord.

## Sectorfile Releases
Full sector file releases are available on [AeroNav GNG](https://files.aero-nav.com/LTXX).

> [!WARNING]
> Releases done in GitHub do not include all essential files for the sectorfile.
